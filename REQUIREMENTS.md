# Take an assessment: requirements

R1 The timer starts when the candidate clicks Start and shows remaining time as mm:ss.
R2 Answers save automatically as soon as they are selected.
R3 Refreshing the page or reopening the link restores the answers and the remaining time.
R4 When the timer reaches 0:00 the assessment submits automatically with every answer selected
   before time ran out, and shows "Time's up".
R5 Score = correct answers / total questions, as a percentage rounded to the nearest whole number.
   Unanswered questions count as incorrect.
R6 The candidate passes when the score reaches the passing score.
